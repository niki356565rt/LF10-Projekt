Voraussetzung: Java 17 Runtime Environment Stand: 24. September 2026

1. Überblick

Diese Anleitung erklärt die Bedienung der Administrationssoftware für das Smart Restaurant. Über das Programm verwalten Sie Mitarbeiter, Speisekarten, Tische und den aktuellen Status eingehender Bestellungen.

2. Programm starten

Öffnen Sie die Anwendung mit einem Doppelklick auf die Datei run.bat im Hauptordner. Alternativ starten Sie das Programm über das Terminal mit folgendem Befehl:

java -cp "lib/sqlite-jdbc.jar;bin" com.smartrestaurant.Main

Nach dem Start öffnet sich das Hauptfenster. Die Benutzeroberfläche unterteilt sich in fünf Reiter.

3. Die Funktionsbereiche

Reiter 1: Mitarbeiterverwaltung

Hier pflegen Sie die Zugänge des Gaststättenpersonals.

  • Neuen Mitarbeiter anlegen: Tragen Sie Name und Benutzernamen in die Textfelder ein, wählen Sie die Rolle (Service, Küche oder Administration) aus und klicken Sie auf Hinzufügen.
  • Mitarbeiter löschen: Wählen Sie die Zeile in der Tabelle aus und klicken Sie auf Löschen.

Reiter 2: Artikelverwaltung

Verwaltung der Speisen- und Getränkekarte mit Preisen.

  • Artikel anlegen: Geben Sie den Namen ein, wählen Sie die Kategorie (z. B. Hauptspeisen) und tragen Sie den Preis ein (z. B. 14.50). Klicken Sie auf Hinzufügen.
  • Artikel löschen: Zeile in der Tabelle markieren und auf Löschen klicken.

Reiter 3: Tischverwaltung

Übersicht der Tische und deren Belegungszustand.

  • Tisch anlegen: Geben Sie die Tischnummer und die Anzahl der Sitzplätze (2 bis 8 Personen) ein. Wählen Sie den Status (frei oder belegt) und klicken Sie auf Hinzufügen.

Reiter 4: Bestellübersicht

Echtzeitübersicht aller eingegangenen Bestellungen.

  • Status weiterleiten: Klicken Sie auf eine Bestellung in der Tabelle und danach auf Status weiterschalten. Der Status durchläuft nacheinander die Stufen: aufgegeben → in Bearbeitung → fertig → serviert → bezahlt.
  • Aktualisieren: Mit dem Button Aktualisieren laden Sie die Tabelle neu.

Reiter 5: System & DB Status

Zeigt technische Informationen zur aktiven SQLite-Datenbank und der Java-Laufzeitumgebung.

4. Häufige Fragen & Fehlerbehebung

Meldung: "Gültigen Preis eingeben!"
Prüfen Sie das Preisfeld. Verwenden Sie Zahlen mit Punkt oder Komma (z. B. 12.50). Buchstaben oder Sonderzeichen sind nicht erlaubt.
Meldung: "Bitte alle Felder ausfüllen!"
Bei der Mitarbeiteranlage müssen sowohl Name als auch Benutzername ausgefüllt sein.
Tabelle zeigt neue Daten nicht an?
Klicken Sie unten im jeweiligen Reiter auf den Aktualisieren-Button.
