1. Übersicht & Systemvoraussetzungen

Die Smart Restaurant Adminsoftware ist die zentrale Steuerungsplattform für moderne Gastronomiebetriebe. Sie ermöglicht die transparente Verwaltung von Personalstammdaten, Speisekartenangeboten, Tischbelegungen sowie die Echtzeit-Verfolgung eingehender Bestellungen.

Minimalanforderungen: Windows 10/11 oder Linux, Java Runtime (JRE 17+), mindestens 2 GB Arbeitsspeicher und Bildschirmauflösung ab 1024 × 768 Pixel.

2. Programmstart

Der Start erfolgt wahlweise per Doppelklick auf run.bat oder über das Terminal:

java -cp "lib/sqlite-jdbc.jar;bin" com.smartrestaurant.Main

Beim ersten Start richtet das System die Datenbankdatei smart_restaurant.db vollautomatisch ein und befüllt sie mit Basistestdaten. Es ist keine manuelle Konfiguration erforderlich.

3. Bedienung der 5 Hauptmodule

👥 1. Mitarbeiterverwaltung (Tab 1)

Erfassung und Verwaltung des Personals:

  • Schnelleingabe: Name und eindeutigen Benutzernamen eingeben, Rolle (Service, Küche, Administration) wählen und auf Hinzufügen klicken.
  • Mitarbeiter-Wizard: Klick auf Neuer Mitarbeiter (Wizard) für geführte Eingabe.
  • Löschen: Mitarbeiter in der Tabelle auswählen und auf Löschen klicken.

🍕 2. Artikelverwaltung / Speisekarte (Tab 2)

Pflege des Speisen- und Getränkeangebots:

  • Artikel anlegen: Name eintragen, Kategorie auswählen (Vorspeisen, Hauptspeisen, Desserts, Getränke), Preis eingeben (z. B. 12,50) und auf Hinzufügen klicken.
  • Artikel-Wizard: Klick auf Neuer Artikel (Wizard) für erweiterte Maskenführung.
  • Preiskonvention: Das System akzeptiert sowohl das deutsche Komma als auch den internationalen Dezimalpunkt.

🪑 3. Tischverwaltung (Tab 3)

Verwaltung der Tische und Sitzplatzkapazitäten:

  • Tisch anlegen: Freie Tischnummer und Sitzplatzanzahl eingeben, Status auf frei setzen und auf Hinzufügen klicken.
  • Tischliste: Liefert den sofortigen Überblick über alle Tische und deren Verfügbarkeit.

📋 4. Bestellübersicht & Status-Workflow (Tab 4)

Steuerung des gastronomischen Kernprozesses:

  • Status weiterschalten: Bestellung markieren und auf Status weiterschalten klicken.
  • Phasen-Reihenfolge: aufgegeben → in Bearbeitung → fertig → serviert → bezahlt
  • Aktualisieren: Klick auf Aktualisieren synchronisiert die Tabelle mit der Datenbank.

ℹ️ 5. System & DB Status / Web-Dashboard (Tab 5)

Technischer Status und mobiler Webzugriff:

  • Anzeige von Datenbankpfad, Verbindungsstatus und SQLite-Treiberversion.
  • Mobiles Dashboard: Über http://localhost:8080 steht ein browserbasiertes Dashboard für Tablets bereit.

4. Typischer Gastronomie-Workflow (Praxisbeispiel)

  1. Gastankunft: Gast wird empfangen, Tischbelegung auf „belegt“ gesetzt.
  2. Bestellaufnahme: Service erfasst Speisen und Getränke; Status steht auf aufgegeben.
  3. Küche: Koch sieht neue Bestellung, schaltet Status auf in Bearbeitung.
  4. Anrichten: Speisen zubereitet; Status wechselt auf fertig.
  5. Servieren: Kellner bringt Speisen zum Gast; Status wechselt auf serviert.
  6. Bezahlung: Rechnung wird beglichen; Status schaltet auf bezahlt; Tisch wird wieder frei.

5. Fehlerbehebung & FAQ

Problem / Meldung Ursache Lösung
„Gültigen Preis eingeben!“ Ungültiges Preisformat (Buchstaben oder Sonderzeichen). Nur Ziffern und Komma/Punkt eingeben (z. B. 14,50).
„Bitte alle Felder ausfüllen!“ Pflichtfeld nicht ausgefüllt. Sicherstellen, dass Name und Benutzername befüllt sind.
Tabelle aktualisiert sich nicht Echtzeit-Synchronisation verzögert. Klick auf die Schaltfläche Aktualisieren.
